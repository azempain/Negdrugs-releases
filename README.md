# NEGDRUGS — signed Windows releases / versions Windows signées

This public repository contains release assets and installation guidance only.
Application source and development tracking remain private. Never upload clinic
records, databases, encrypted backups, device vaults or private signing keys here.

Ce dépôt public contient uniquement les programmes signés et les instructions
d’installation. Le code source et le suivi du développement restent privés.
Aucun dossier clinique, base de données, sauvegarde, coffre d’appareil ou clé privée
ne doit être publié ici.

Approved releases will appear in [Releases](https://github.com/azempain/Negdrugs-releases/releases).
No clinical release is approved or published yet. A draft is not permission to
install on clinic machines. The deployment owner must complete publisher trust,
the exact installer upgrade/recovery drill and finance/operational acceptance.

Les versions acceptées seront disponibles dans [Releases](https://github.com/azempain/Negdrugs-releases/releases).
Aucune version clinique n’est encore acceptée ou publiée. Un brouillon n’autorise
pas l’installation en clinique. Le responsable du déploiement doit vérifier la
confiance de l’éditeur, la mise à niveau/récupération du programme exact et les
acceptations financières et opérationnelles.

Windows 10/11 x64 only. Use the same MSI or NSIS installer family and Windows
profile as the existing installation. Preserve an encrypted off-device backup
before upgrade; never remove application data to bypass an installer refusal.
Optional signed updates require no GitHub credential and are separate from
offline hospital workflows. Current receipt issuance is retained.

Windows 10/11 x64 uniquement. Conservez la famille MSI ou NSIS et le profil Windows
de l’installation existante. Préservez une sauvegarde chiffrée hors ordinateur
avant la mise à niveau ; ne supprimez jamais les données pour contourner un refus.
Les mises à jour signées facultatives ne demandent aucun identifiant GitHub et
restent séparées des parcours hospitaliers hors connexion. Les reçus actuels sont
conservés.
